# 0013 見た目は平成初期の個人ホームページと掲示板のパロディにし、中身は今の技術で作る

- 日付: 2026-10-19
- 状態: 採用

## 背景

旧ブログは Chakra UI の今風の見た目だった。新しいブログは「一見は昔の掲示板っぽいのに爆速で、実はかなりリッチ」なパロディにする。参考は [阿部寛のホームページ](https://abehiroshi.la.coocan.jp/)。左のフレームに「●」付きのメニュー、右に大きな見出しと表で組んだ本文、「★★★ 最新情報 ★★★」の見出し、太字の注意書きが並ぶ。

## 決定

- **見た目**: HTML 3.2 の頃の既定の見た目を基本にする。白地に黒の明朝、青い下線付きのリンク（訪問済みは紫）、凹凸の枠の表、`<hr>`。左に「●」のメニュー列を置き、フレームで区切ったように見せる（本物の `<frameset>` は使わない）
- **掲示板**: 記事の一覧は掲示板の表（No.・題名・カテゴリ・投稿日）にし、記事のページは投稿の見出し（No.・投稿者・投稿日）から始める。No. は公開日の古い順の連番
- **パソコン通信モード**: OS がダークモードのときは、黒地に緑の文字の端末風にする（`prefers-color-scheme: dark`）。切り替えボタンは置かない
- **中身は今の技術**（読者には見えないところでリッチにする）
  - CSS のビュー遷移（`@view-transition`）で、ページの移り変わりを滑らかにする
  - Speculation Rules（`<script type="speculationrules">`）で、リンクにカーソルを載せた時点で次のページを先読みする
  - 構造化データ、目次、リンクカード、コードの装飾は ADR-0008・0011 のとおり
- **動き**: 「NEW!」の点滅だけにする（公開から 14 日以内の記事）。`prefers-reduced-motion` のときは止める
- **嘘をつかない**: アクセスカウンターは置かない（数える仕組みが無いため）。代わりに、同じ見た目で記事数を出す

## 理由

- パロディの見た目は、既定に近い HTML と CSS だけで作れるので、軽さと両立する。「古いのに速い」こと自体が見せ場になる
- 掲示板の No. や投稿者・投稿日は、ブログの記事の情報（順番・作者・日付）と一対一で対応し、飾りではなく意味を持つ
- Speculation Rules は JSON を宣言するだけで、JS を実行しない。対応ブラウザでは遷移がほぼ一瞬になり、非対応のブラウザでは何も起きない

## 影響・トレードオフ

- 明朝の本文はシステムのフォントに頼るので、OS によって見た目が変わる（Web フォントは読まない規則を守る）
- 古い見た目でも、文字の大きさ・行間・コントラスト・キーボードの操作は今の基準を守る（[`docs/specs/design.md`](../specs/design.md)）
- Speculation Rules の先読みは、記事と一覧のページに限る（`/admin/` や外部リンクは先読みしない）
- `rules/architecture.md` のクライアント JS の許可リストに、Speculation Rules（JS を実行しない宣言）を足す
