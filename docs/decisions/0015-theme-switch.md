# 0015 表示の切り替え（自動・昼・夜）を置く

- 日付: 2026-10-19
- 状態: 廃止（→ 0016）

## 背景

ADR-0007 と ADR-0013 では、夜の「パソコン通信」モードを OS の設定（`prefers-color-scheme`）にだけ従わせ、切り替えのボタンは置かないとしていた。読む人が OS の設定と別に、昼と夜を選べるようにしたい。

## 決定

- 左のメニュー列に「表示」の切り替えを置く。選べるのは「自動（OS に合わせる）」「昼（ホームページ）」「夜（パソコン通信）」の 3 つ。見た目は昔のフォームのラジオボタン
- 選んだものは `localStorage` に残し、次にどのページを開いても同じにする。「自動」は残した値を消す
- ページを描く前に `<head>` の小さなスクリプトで `<html data-theme>` を付け、ちらつかせない（一瞬だけ違う色で描かない）
- 色は CSS 変数だけで切り替える。`data-theme` が無いときは `prefers-color-scheme` に従い、`data-theme="light"`・`"dark"` のときはそれに従う
- 切り替えた瞬間は、対応するブラウザでビュー遷移（`document.startViewTransition`）でつなぐ。`prefers-reduced-motion` のときは使わない
- JS が動かないときは、切り替えを出さない（押しても何も起きない部品を見せない）。そのときも OS の設定には従う

## 理由

- 昼と夜で見た目が大きく違う（ホームページとパソコン通信）ので、読む人が好きな方を選べると、パロディを両方楽しめる
- `<head>` で先に属性を付ければ、保存した表示を選んでいても、描いてから色が変わることはない
- `localStorage` が使えない（プライベートブラウズなど）ときも、その場では切り替わり、ページの表示は壊れない

## 影響・トレードオフ

- クライアント JS が 2 つ増える（`<head>` の数行と、切り替えの部品）。`rules/architecture.md` の許可リストに足す
- ADR-0007 の「ダークモード」の行と、ADR-0013 の「切り替えボタンは置かない」は、この ADR に置き換える
- 撮影（Screenshots ワークフロー）は、OS の設定とは逆の表示を選んだ場合も撮る
