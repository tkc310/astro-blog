# 0016 見た目は白地のシンプルなデザインにし、表示の切り替えは置かない

- 日付: 2026-10-19
- 状態: 採用

## 背景

ADR-0013 で平成初期の個人ホームページと掲示板のパロディにし、ADR-0015 で昼（ホームページ）と夜（パソコン通信）を切り替えられるようにした。作ってみた結果、レトロな路線をやめ、白地のシンプルでスタイリッシュな見た目にすることにした。

## 決定

- 見た目は白地のシンプルなデザインにする。詳細は [`docs/specs/design.md`](../specs/design.md)
- ダークモードと表示の切り替えは置かない。`prefers-color-scheme` にも従わず、いつも白地で出す（`color-scheme: light`）
- ADR-0013 と ADR-0015 は廃止する。ただし ADR-0013 で入れた次の 2 つは、見た目と関係なく速さに効くので残す
  - CSS のビュー遷移（`@view-transition`）。一覧の題名から記事の見出しへつなぐ
  - Speculation Rules（`<script type="speculationrules">`）での先読み。JS を実行しない宣言なので、クライアント JS に数えない
- 文字は引き続きシステムのフォントだけを使う（ADR-0007）

## 理由

- 白地 1 つに絞ると、色のトークンと検査（撮影）が半分になり、保守が軽くなる
- 表示の切り替えに使っていた `<head>` のスクリプトと切り替えの部品が無くなり、クライアント JS が減る
- 記事を読むことに集中できる見た目にしたい

## 影響・トレードオフ

- OS をダークモードにしている読者にも白地で出る
- ADR-0007 の「ダークモード」の行は、この ADR に置き換える
- 掲示板の No.・アクセスカウンター風の記事数・「NEW!」の点滅はやめる
