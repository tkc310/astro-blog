# デザイン 指示書

方針: [ADR-0016](../decisions/0016-simple-white-design.md)

白地に黒の文字で、記事を読むことに集中できる静かな見た目。余白を広く取り、和文の組版を丁寧にする。目立たせるのは一覧の「年」の数字 1 つだけで、それ以外は余白と文字の大きさ・太さの差で組む。枠・影・カードは使わない。

---

## 1. 色

白と黒とグレーだけで組む。色を使うのはカテゴリの小さな丸だけにする。

| 名前       | 値        | 使いどころ                                       |
| ---------- | --------- | ------------------------------------------------ |
| `--paper`  | `#FFFFFF` | 地                                               |
| `--strong` | `#000000` | 見出し・題名・サイト名・年の数字・フォーカスの線 |
| `--ink`    | `#222222` | 本文                                             |
| `--muted`  | `#6B6B6B` | 日付・説明・補足（白地で 5.3:1）                 |
| `--faint`  | `#B5B5B5` | リンクの下線（文字の色は本文と同じ）             |
| `--line`   | `#E6E6E6` | 区切りの線・コードの枠                           |
| `--wash`   | `#F7F7F7` | コードブロック・インラインのコードの地           |

- リンクは本文と同じ色で、薄いグレーの下線を引く。カーソルを載せると下線が黒になる
- カテゴリには旧ブログの色の名前（blue・green など）を引き継ぎ、名前の前の小さな丸にだけ、落ち着いた色に置き換えて付ける
- ダークモードは置かない（ADR-0016）

## 2. 文字

| 役割         | フォント（システムのものだけ）                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------- |
| 本文・見出し | `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic UI", Meiryo, sans-serif` |
| コード       | `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`                                       |

- 本文 16px、行間 2、字間 0.04em、1 行の最大幅 38em
- 見出し: 太さ 600、字間 0.06em、かなを詰める（`font-feature-settings: "palt"`）。文節の切れ目で折り返す（`word-break: auto-phrase`）
- 年の数字: 3.5rem・太さ 200（細く大きく）。日付は `2026.10.19` の形で、数字の幅をそろえる（`tabular-nums`）
- 和文と欧文のあいだを自動で空け（`text-autospace`）、行頭の約物を詰める（`text-spacing-trim`）。対応しないブラウザでは何も起きない

## 3. 配置

```

  tkc310.com                                     記事   About
  記事
  ● インフラ   ● フロントエンド

  2026                                   ← 年の数字（大きく、細く、黒）
  10.19   ブログを Astro と Cloudflare に引っ越しました
          microCMS と Next.js で作っていたブログを…（説明）
          ● フロントエンド
  10.12   Cloudflare Workers の静的アセットで…

  ───────────────────────────────────────────────
  GitHub  X  Zenn  Qiita  LAPRAS            © 2021-2026 tkc310

スマホ: 1 列。日付は題名の上に置く。
```

- 本文の列は中央に置き、最大幅 44rem（記事は本文 38em ＋ 目次で最大 62rem）。中身は左寄せで組む
- ヘッダーとフッターは本文の列と同じ幅にそろえる

## 4. 部品

| 部品         | 見た目                                                                                          |
| ------------ | ----------------------------------------------------------------------------------------------- |
| ヘッダー     | 左にサイト名（`/` へ）、右に「記事」（`/articles`）と「About」（`/`）。今いるページは下線で示す |
| 年の数字     | 記事を年でまとめ、年を大きく細い黒の数字で示す                                                  |
| 記事の行     | 日付（左の狭い列）・題名・説明（1〜2 行）・カテゴリ                                             |
| カテゴリ     | 小さな丸（カテゴリの色）＋名前                                                                  |
| 記事の見出し | カテゴリと日付（小さく、補足の色）の下に題名                                                    |
| 目次         | PC は本文の右に固定（小さな文字）、スマホは本文の前に `<details>` で畳む                        |
| 前後の記事   | 本文の下に「前の記事」「次の記事」と題名を左右に並べる                                          |
| ページ送り   | 「前へ」「1 2 3」「次へ」。今のページは太字                                                     |
| フッター     | 線の下に各 SNS へのリンクと著作権表示                                                           |

## 5. ページ

| ページ                           | 中身                                                                      |
| -------------------------------- | ------------------------------------------------------------------------- |
| トップ（`/`）                    | 自己紹介（名前・自己 PR）、最近の記事 3 件、LAPRAS の活動一覧（ADR-0012） |
| 記事一覧（`/articles`）          | 見出し「記事」、カテゴリへのリンク、年でまとめた記事、ページ送り          |
| 一覧 2〜（`/articles/page/<n>`） | 年でまとめた記事、ページ送り                                              |
| 記事                             | 見出し（カテゴリ・日付・題名）、目次、本文、前後の記事                    |
| カテゴリ                         | カテゴリ名と説明、年でまとめた記事                                        |
| 404                              | 見つからなかったことと、記事の一覧へのリンク                              |

`/about` は `/` へ 301 する（同じ内容を 2 つの URL で出さない）。

## 6. 動きと先読み

- ページの移り変わりは CSS のビュー遷移（`@view-transition`）。一覧の題名に `view-transition-name` を付け、記事の題名へつなぐ
- Speculation Rules で、サイト内のリンクを `moderate`（カーソルを載せたとき）で先読みする。`/admin/` は除く
- それ以外の動きは付けない。`prefers-reduced-motion: reduce` ではビュー遷移も止める

## 7. 守ること

- キーボードで操作でき、フォーカスが見える（`:focus-visible` に黒の 2px の線）
- 本文とリンクのコントラスト 4.5:1 以上
- 拡大しても横にはみ出さない。長い URL やコードは折り返すか、その要素の中で横に流す
- 印刷するときはヘッダーのナビとフッターのリンクを隠す
