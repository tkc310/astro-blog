# デザイン 指示書

方針: [ADR-0013](../decisions/0013-retro-homepage-design.md)。参考: [阿部寛のホームページ](https://abehiroshi.la.coocan.jp/)

「見た目は HTML 3.2、中身は 2026」。既定に近い HTML の見た目を基本にし、目立たせるのは左のメニュー列と掲示板の一覧の 2 つだけにする。それ以外は飾らない。

---

## 1. 色

| 名前         | 昼（既定） | 夜（パソコン通信） | 使いどころ                           |
| ------------ | ---------- | ------------------ | ------------------------------------ |
| `--paper`    | `#FFFFFF`  | `#000000`          | 地                                   |
| `--ink`      | `#000000`  | `#33FF33`          | 本文                                 |
| `--link`     | `#0000EE`  | `#FFFF55`          | リンク                               |
| `--visited`  | `#551A8B`  | `#55FFFF`          | 訪問済みのリンク                     |
| `--alert`    | `#FF0000`  | `#FF5555`          | 「NEW!」、注意書き                   |
| `--frame-hi` | `#DFDFDF`  | `#33FF33`          | 枠の明るい辺（凹凸の枠）             |
| `--frame-lo` | `#808080`  | `#118811`          | 枠の暗い辺                           |
| `--counter`  | `#000000`  | `#000000`          | 記事数の数字の地（文字は `#33FF33`） |

- カテゴリの色は旧ブログの値（blue・green・red など）を HTML の色名のまま使い、名前の前の「■」にだけ付ける。文字には使わない（黄色や水色は白地で読めないため）
- コントラストは本文・リンクとも 4.5:1 以上（昼の `#0000EE` は 9.4:1）

## 2. 文字

| 役割                 | フォント（システムのものだけ）                                             |
| -------------------- | -------------------------------------------------------------------------- |
| 本文・見出し         | 明朝: `"Hiragino Mincho ProN", "Yu Mincho", YuMincho, "MS PMincho", serif` |
| 掲示板の情報・コード | 等幅: `ui-monospace, "Osaka-Mono", "MS Gothic", monospace`                 |
| 夜のモード           | すべて等幅                                                                 |

- 本文 16px、行間 1.9、1 行 40 字前後（本文の最大幅 40em）
- 見出しは HTML の既定の大きさの比（h1 2em、h2 1.5em、h3 1.17em）を保つ
- 太字は注意書きと見出しだけ。強調のための色分けはしない

## 3. 配置

```
PC（48em 以上）
┌───────────┬─────────────────────────────────────┐
│ ●トップ    │        tkc310_log のホームページ      │  ← 中央寄せの大見出し
│ ●記事一覧  │ ─────────────────────────────────── │
│ ●カテゴリ  │  管理人 tkc310 ／ 記事数 [000012]     │  ← 左を空けた 2 列の表
│   ■フロント │  ★★★ 最新の書き込み ★★★            │
│ ●管理者    │  ┌No.┬題名──────────┬カテゴリ┬投稿日┐ │  ← 掲示板の表
│ ●RSS      │  └───┴──────────────┴────────┴──────┘ │
│           │  [1] [2] 次の10件>>                   │
│ (フレーム境)│ ─────────────────────────────────── │
│           │  注意書き（太字）・Copyright            │
└───────────┴─────────────────────────────────────┘

スマホ（48em 未満）: メニュー列は上に移り、「●」のリンクが横に並んで折り返す。掲示板の表は 1 件ずつの段組みにする。
```

- 左のメニュー列は幅 11em、右との境に凹凸の線（`border-right: 4px ridge`）を引いてフレームに見せる。スクロールしても列は残る（`position: sticky`）
- 本文の列は左寄せ。トップの大見出しと、ページの下の注意書きだけ中央寄せにする

## 4. 部品

| 部品         | 見た目                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| メニュー     | 「●」＋リンク。カテゴリは一段下げて「■」（カテゴリの色）＋名前                                         |
| 掲示板の表   | `border: 2px outset`、セルは `1px inset`。No. は等幅で右寄せ。公開 14 日以内は題名の後ろに「NEW!」     |
| 投稿の見出し | `[No.12] 題名` を h1 に、その下に「投稿者：tkc310　投稿日：2026/10/19(月)　カテゴリ：■フロントエンド」 |
| 目次         | 凹凸の枠の表で「目次」。h2・h3。PC は本文の右に固定、スマホは本文の前に `<details>` で畳む             |
| 前後の記事   | 「◀ 前の書き込み ｜ 掲示板に戻る ｜ 次の書き込み ▶」                                                   |
| 記事数       | 黒地に緑の数字 6 桁（`000012`）。アクセスカウンターの見た目を借りるが、数えるのは記事数                |
| ページ送り   | `[1] [2] [3] 次の10件>>`。今のページは括弧なしの太字                                                   |
| 注意書き     | 太字・中央寄せ: 「当ブログはリンクフリーです。記事の引用は出典を書いていただければ歓迎します。」       |
| 著作権表示   | `Copyright (C) 2021-<今年> tkc310. All Rights Reserved.`                                               |

## 5. ページ

| ページ   | 中身                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| トップ   | 大見出し、管理人と記事数と最終更新日の表、「★★★ 最新の書き込み ★★★」の掲示板の表、ページ送り |
| 一覧 2〜 | トップと同じ掲示板の表とページ送り（大見出しの表は出さない）                                 |
| 記事     | 投稿の見出し、目次、本文、前後の記事                                                         |
| カテゴリ | 「■カテゴリ名 の書き込み」の見出し、説明、掲示板の表                                         |
| About    | 「管理者について」。自己 PR、LAPRAS の活動一覧（ADR-0012）                                   |
| 404      | 「お探しのページは見つかりませんでした。」とトップへのリンク（昔の「工事中」の雰囲気で）     |

## 6. 動きと先読み

- 「NEW!」の点滅（1 秒周期の `steps()`）だけ。`prefers-reduced-motion: reduce` では止める
- ページの移り変わりは `@view-transition { navigation: auto; }`。投稿の見出しに `view-transition-name` を付け、一覧の題名から記事の見出しへつながって見せる
- Speculation Rules で、サイト内のリンクを `moderate`（カーソルを載せたとき）で prerender する。`/admin/` は除く

## 7. 守ること（古い見た目でも）

- キーボードで操作でき、フォーカスが見える（`outline: 2px dotted` を `:focus-visible` に）
- 文字は 16px 以上、行間 1.9。拡大しても横にはみ出さない
- 夜のモードも含め、本文とリンクのコントラスト 4.5:1 以上
- 表で組むのは表のデータ（掲示板の一覧・プロフィール）だけで、段組みは CSS グリッドで作る
- 印刷するときはメニュー列を隠す
