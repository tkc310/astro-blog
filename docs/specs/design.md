# デザイン 指示書

方針: [ADR-0016](../decisions/0016-simple-white-design.md)

白地に、記事を読むことに集中できる静かな見た目。目立たせるのは、一覧の「年」の数字 1 つだけにし、それ以外は余白と文字の大きさの差で組む。枠・影・カードは使わない。

---

## 1. 色

| 名前       | 値        | 使いどころ                                     |
| ---------- | --------- | ---------------------------------------------- |
| `--paper`  | `#FFFFFF` | 地                                             |
| `--ink`    | `#1F2328` | 本文・見出し                                   |
| `--muted`  | `#5E6772` | 日付・説明・補足（白地で 5.9:1）               |
| `--line`   | `#E7E9EC` | 区切りの線・コードの枠                         |
| `--accent` | `#24489C` | リンク・フォーカス・年の数字（藍。白地で 8:1） |
| `--wash`   | `#F5F6F8` | コードブロック・引用の地                       |

- ダークモードは置かない（ADR-0016）
- カテゴリには旧ブログの色の名前（blue・green など）を引き継ぎ、名前の前の小さな丸にだけ、落ち着いた色に置き換えて付ける

## 2. 文字

| 役割         | フォント（システムのものだけ）                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------- |
| 本文・見出し | `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic UI", Meiryo, sans-serif` |
| コード       | `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`                                       |

- 本文 17px、行間 1.9、1 行の最大幅 38em
- 見出し: 記事の題名 2rem（行間 1.45）、h2 1.45rem、h3 1.15rem。太さは 700
- 日付は `2026.10.19` の形で、数字の幅をそろえる（`font-variant-numeric: tabular-nums`）

## 4. 部品

| 部品         | 見た目                                                                   |
| ------------ | ------------------------------------------------------------------------ |
| ヘッダー     | 左にサイト名（太字）、右に「記事」「About」。今いるページは下線で示す    |
| 年の数字     | 記事を年でまとめ、年を大きな数字（2.75rem・藍）で示す                    |
| 記事の行     | 日付（左の狭い列）・題名・説明（1〜2 行）・カテゴリ                      |
| カテゴリ     | 小さな丸（カテゴリの色）＋名前                                           |
| 記事の見出し | カテゴリと日付（小さく、補足の色）の下に題名                             |
| 目次         | PC は本文の右に固定（小さな文字）、スマホは本文の前に `<details>` で畳む |
| 前後の記事   | 本文の下に「前の記事」「次の記事」と題名を左右に並べる                   |
| ページ送り   | 「前へ」「1 2 3」「次へ」。今のページは太字                              |
| フッター     | 線の下に各 SNS へのリンクと著作権表示                                    |

## 5. ページ

| ページ   | 中身                                                                      |
| -------- | ------------------------------------------------------------------------- |
| トップ   | サイトの紹介 1 文、カテゴリへのリンク、年でまとめた記事の一覧、ページ送り |
| 一覧 2〜 | 年でまとめた記事の一覧、ページ送り                                        |
| 記事     | 見出し（カテゴリ・日付・題名）、目次、本文、前後の記事                    |
| カテゴリ | カテゴリ名と説明、年でまとめた記事の一覧                                  |
| About    | 名前と自己紹介、LAPRAS の活動一覧（ADR-0012）                             |
| 404      | 見つからなかったことと、トップへのリンク                                  |

## 6. 動きと先読み

- ページの移り変わりは CSS のビュー遷移（`@view-transition`）。一覧の題名に `view-transition-name` を付け、記事の題名へつなぐ
- Speculation Rules で、サイト内のリンクを `moderate`（カーソルを載せたとき）で先読みする。`/admin/` は除く
- それ以外の動きは付けない。`prefers-reduced-motion: reduce` ではビュー遷移も止める

## 7. 守ること

- キーボードで操作でき、フォーカスが見える（`:focus-visible` に藍の 2px の線）
- 本文とリンクのコントラスト 4.5:1 以上
- 拡大しても横にはみ出さない。長い URL やコードは折り返すか、その要素の中で横に流す
- 印刷するときはヘッダーのナビとフッターのリンクを隠す
