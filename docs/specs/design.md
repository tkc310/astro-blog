# デザイン 指示書

方針: [ADR-0016](../decisions/0016-simple-white-design.md)

白地に黒の文字で、記事を読むことに集中できる静かな見た目。余白を広く取り、和文の組版を丁寧にする。目立たせるのは各ページの題（大きく細い文字を、字間を広く取って置く）1 つだけで、それ以外は余白と文字の大きさ・太さ・字間の差で組む。枠・影・カード・飾りの線は使わない。色・文字の大きさ・余白は `:root` の変数（`--text-*`・`--space-*`）の階段から選ぶ。

---

## 1. 色

白と黒とグレーだけで組む。色を使うのはカテゴリの小さな丸だけにする。

| 名前       | 値        | 使いどころ                                       |
| ---------- | --------- | ------------------------------------------------ |
| `--paper`  | `#FFFFFF` | 地                                               |
| `--strong` | `#000000` | 見出し・題名・サイト名・フォーカスの線・選択範囲 |
| `--ink`    | `#1C1C1C` | 本文                                             |
| `--muted`  | `#6F6F6F` | 日付・説明・補足（白地で 5.0:1）                 |
| `--faint`  | `#C2C2C2` | リンクの下線（文字の色は本文と同じ）             |
| `--line`   | `#ECECEC` | 区切りの線（フッター・前後の記事・目次）         |
| `--wash`   | `#F6F6F6` | コードブロック・インラインのコードの地           |

- リンクは本文と同じ色で、薄いグレーの下線を文字に寄せて（0.2em）引く。カーソルを載せると下線が黒になる。題名やナビのリンクは、ふだんは下線を消し、カーソルを載せたときだけ出す
- 文字を選ぶと、黒地に白で反転する
- カテゴリには旧ブログの色の名前（blue・green など）を引き継ぎ、名前の前の小さな丸にだけ、落ち着いた色に置き換えて付ける
- ダークモードは置かない（ADR-0016）

## 2. 文字

| 役割         | フォント（システムのものだけ）                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------- |
| 本文・見出し | `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic UI", Meiryo, sans-serif` |
| コード       | `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`                                       |

- 本文 16px・行間 2・字間 0.05em。記事の本文だけ 17px・行間 2.05、1 行の最大幅 36em
- 文字の大きさは 1.25 倍ずつの階段（`--text-2xs` 12px 〜 `--text-lg` 22px、`--text-xl`・`--text-display` は画面の幅で伸び縮み）
- ページの題: `--text-display`（36〜52px）・太さ 200・字間 0.16em。このサイトでいちばん目立つ要素
- 見出し: 太さ 600、字間 0.06em（記事の題は欧文が開きすぎないよう 0.03em）、かなを詰める（`font-feature-settings: "palt"`）。文節の切れ目で折り返す（`word-break: auto-phrase`）
- 小さな文字（日付・ナビ・カテゴリ・補足）は字間を 0.06〜0.14em 開け、小さくても詰まって見えないようにする
- 日付は `2026.10.19` の形で、数字の幅をそろえる（`tabular-nums`）
- 和文と欧文のあいだを自動で空け（`text-autospace`）、行頭の約物を詰める（`text-spacing-trim`）。対応しないブラウザでは何も起きない

## 3. 配置

```
PC（記事一覧 /）
  tkc310.com                                記事   私について

  記            事                       ← ページの題（大きく、細く、字間を広く）
  ● インフラ   ● フロントエンド

  2026.10.19   ブログを Astro と Cloudflare に引っ越しました
               microCMS と Next.js で作っていたブログを…（説明）
               ● フロントエンド

  2026.10.12   Cloudflare Workers の静的アセットで…

  ───────────────────────────────────────────────
  GitHub  X  Zenn  Qiita  LAPRAS            © 2021-2026 tkc310

スマホ: 1 列。日付は題名の上に置く。
```

- 列は中央に置き、どのページも最大幅 42rem。ページを移っても、ヘッダーと本文の左端は動かない。中身は左寄せで組む
- 記事と私についての目次は、幅 80rem 以上では列の外（右の余白）に置いて追従させ、それより狭いときは本文の前に畳み、スクロール中は画面上端の sticky バーに収めて追尾する（畳んでいるあいだは今の見出し名も出す）
- ヘッダーとフッターは本文の列と同じ幅にそろえる
- 行と行は線で区切らず、余白で分ける

## 4. 部品

| 部品         | 見た目                                                                                                                                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ヘッダー     | 左にサイト名（`/` へ）、右に「記事」（`/`）と「私について」（`/about`）。今いるページは黒と下線で示す                                                                                                                 |
| ページの題   | 大きく細い文字を、字間を広く取って置く（`PageHeader`）。カテゴリでは上に「カテゴリ」、下に説明                                                                                                                        |
| 記事の行     | 新しい順にまとめずに並べる。日付 `2026.10.19`（左の列）・題名・説明（1〜2 行）・カテゴリ                                                                                                                              |
| カテゴリ     | 小さな丸（カテゴリの色）＋名前                                                                                                                                                                                        |
| 記事の見出し | カテゴリと日付（小さく、補足の色）の下に題名。本文の見出しはレベルに応じた `##` / `###` を前に出し（題名の h1 には付けない）、クリックでその見出しへページ内で移動する。`##` は列の外へぶら下げず、見出しの前に並べる |
| 目次         | 広い画面は列の外の右に追従、狭い画面は本文の前に `<details>` で畳み sticky 追尾（閉じているときは今の見出し名をバーに出し、右端の細い山形で開閉を示す）。今読んでいる見出しに黒い印                                   |
| 前後の記事   | 本文の下に「前の記事」「次の記事」と題名を左右に並べる                                                                                                                                                                |
| ページ送り   | 「前へ」「1 2 3」「次へ」。今のページは黒と下線                                                                                                                                                                       |
| アイコン     | 円いプロフィールの画像（`public/`）。ファビコン（`favicon.ico`・`icon-192.png`・`apple-touch-icon.png`）と、私についての題の上（56px、名前と並べる）に使う                                                            |
| フッター     | 線の下に各 SNS へのリンクと著作権表示                                                                                                                                                                                 |

## 5. ページ

| ページ                           | 中身                                                                                                                                                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 記事一覧（`/`）                  | 題「記事」、カテゴリへのリンク、新しい順の記事、ページ送り                                                                                                                         |
| 一覧 2〜（`/articles/page/<n>`） | 題「記事」と何ページ目か、新しい順の記事、ページ送り                                                                                                                               |
| 私について（`/about`）           | 題「私について」（上にアイコンと名前）、目次（記事詳細と同じ）、自己紹介（`src/content/profile/about.md`）、線と余白で区切って LAPRAS の活動一覧（ADR-0017）。記事の一覧は置かない |
| 記事                             | 見出し（カテゴリ・日付・題名）、目次、本文、前後の記事                                                                                                                             |
| カテゴリ                         | カテゴリ名と説明、新しい順の記事                                                                                                                                                   |
| 404                              | 見つからなかったことと、記事の一覧・私についてへのリンク                                                                                                                           |

`/articles`（と `/articles/`）と `/articles/page/1` は `/` へ 301 する。同じ一覧を 2 つの URL で出さない（`check-output` が検査する）。

## 6. 動きと先読み

- ページの移り変わりは CSS のビュー遷移（`@view-transition`）。一覧の題名に `view-transition-name` を付け、記事の題名へつなぐ
- Speculation Rules で、サイト内のリンクを `moderate`（カーソルを載せたとき）で先読みする。`/admin/` は除く
- それ以外の動きは付けない。`prefers-reduced-motion: reduce` ではビュー遷移も止める

## 7. 守ること

- キーボードで操作でき、フォーカスが見える（`:focus-visible` に黒の 2px の線）
- 本文とリンクのコントラスト 4.5:1 以上
- 拡大しても横にはみ出さない。長い URL やコードは折り返すか、その要素の中で横に流す
- 印刷するときはヘッダーのナビとフッターのリンクを隠す
